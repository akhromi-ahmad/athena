# Product

## Register
product

## Users
- Developers learning Laravel who want to see best-practice implementations.
- Ahmad Akhromi (owner) learning and solidifying Laravel concepts phase by phase.
- AI coding assistants collaborating on building and reviewing code.

## Product Purpose
Athena is a structured Laravel learning project built from scratch to study, implement, and master industry-standard backend architecture and clean frontend layouts (like dashboard asset systems).

## Brand Personality
- Clean
- Utilitarian
- Structured

## Anti-references
- "AI generic template" vibes: excessive drop shadows with thin borders, over-rounded elements (`border-radius: 32px+`), neon colors, and low contrast.
- Spaghetti logic in controllers or hardcoded credentials.
- Low-contrast text (below 4.5:1 ratio) that is hard to read.

## Design Principles
- **Functionality First**: Every visual element serves a purpose; no decorative noise.
- **Learn by Understanding**: The codebase is written to be readable and self-documenting.
- **Strict Consistency**: Layout structures, margins, and typographies are strictly token-driven.

## Accessibility & Inclusion
- Contrast ratio ≥ 4.5:1 for body copy.
- Minimum font size of 14px (ideally 16px).
- Responsive layouts at all breakpoints.
